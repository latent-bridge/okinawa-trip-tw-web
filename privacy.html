● 隱私權政策

我們怎麼處理你的資料

簡單說：我們盡量不碰你的個人資料。以下是誠實的說明。

生效日：2026-06-14

我們收集什麼

本網站是一個靜態網站，沒有會員、沒有登入、沒有需要你填寫個資的表單。我們不主動收集你的姓名、電話、地址等個人資料。

若你主動寫 Email 給我們，我們只會看到你信中提供的資訊（如你的信箱與來信內容），並僅用於回覆你；不會作其他用途，也不會提供給第三方。

流量分析（Cloudflare Web Analytics）

為了了解哪些內容對你有幫助，我們使用 Cloudflare Web Analytics。它是一個注重隱私的分析工具：

  • 不使用 cookie，也不在你的裝置上留下追蹤識別碼。
  • 不建立跨網站的使用者輪廓，不蒐集可識別個人的資料。
  • 只彙整匿名的整體數據，例如造訪頁面、來源、國家、裝置類型等。

詳情可參閱 Cloudflare Web Analytics 的說明。

Cookie

本站不主動設定追蹤用的 cookie。你的瀏覽器可能會在本機儲存少量設定（例如你選擇的語言），這些資料只留在你的裝置上，我們看不到。當你點擊外部或合作連結後，對方網站可能會依其政策設定 cookie，這部分由該網站負責。

第三方與合作連結

本站含有前往第三方平台的連結（如 KKday、Klook、Tabirai、各船公司官方頁等），其中部分為合作連結。當你點擊並前往這些網站後，你的資料將依對方的隱私政策處理，不在本站控制範圍內。合作連結的說明請見 免責聲明與合作揭露。

本站的網頁字型由 Google Fonts 提供、網站託管於 GitHub Pages、分析由 Cloudflare 提供，這些服務在提供功能時可能取得必要的連線資訊（如 IP 位址），並適用其各自的隱私政策。

你的權利與聯絡方式

如果你曾寫信給我們，並希望我們刪除你的來信資料，或對隱私有任何疑問，歡迎透過 hi@okinawa-kaupue.com 與我們聯絡。

政策更新

當網站新增功能（例如社群、訂閱、體驗預約）時，我們會更新本政策，並在此頁標註新的生效日。
